# Simple Kanban Board

A small React board with three columns: To Do, In Progress, and Done.

## Run

From this folder:

```sh
npm install
npm run dev
```

Build for production with `npm run build`.

## Use

- Enter a task and click Add. New tasks start in To Do.
- Drag a task into another column to change its status.
- Click Delete to remove a task.
- Tasks are saved automatically in this browser using localStorage.

The app uses React and plain CSS, with no extra UI libraries or backend.
